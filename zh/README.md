### 第一部 保单

一家保险公司从一张纸开始。在有保单组合、有准备金、有理赔之前，先有一张保单：它承保什么，赔付多少，要价几何，谁来买它。保单写错了，生意后面的一切都补救不了。

前三章讲的就是保单。当你是写下期权的那个人时，期权究竟是什么；如何判断价格是否公道；以及这一行最古老的纪律：决定哪些风险根本不写。

### 第二部 保单组合

一张保单是一次押注。一千张保单，定价得当、分散得开，才是一门生意。两者的区别不在聪明，而在算术——这笔算术只有在保单数量多、单张规模小、又不都落在同一条街上时才成立。

第四至第六章讲保单组合：为什么规模比任何一次预测都重要，为什么同一片海岸上的一百张保单其实只是一张，以及为什么每一张保单在卖出之前都必须写明限额。

### 第三部 理赔与资本

保费是在好天气里收的。保险公司要到理赔的季节才见分晓：赔得有多快，留了多少底，以及一年算下来，赚的是否多过赔的。

第七至第九章讲理赔与资本：以已知的代价了结一个受到考验的仓位，而不是跟市场争辩；让你在别人写不了时仍能继续承保的准备金；以及那个告诉你自己经营的是生意还是慈善的比率。

### 第四部 巨灾与长久

保险的历史是用巨灾之年写成的。那些盈利了十年的公司，在一周之内消失，不是因为平常日子定价定错了，而是因为它们从未设想过那个不平常的日子。

最后四章讲长期：市场称为百年一遇、却每隔几年就送来一次的风暴；保险人为自己买的保险；保费在赚到手之前被持有的那份耐心；以及让一家公司活得比创始人更久的那套纪律。
